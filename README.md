Music Disk Builder  
==================  
  
A small Windows utility for building Music Disk archives.  
Based on Music Disks from Phantasy Star Online.  
Generates deterministic metadata for given MP3s.  

音楽ディスクアーカイブを構築するための小さなWindowsユーティリティ。  
ファンタシースターオンラインの音楽ディスクに基づいています。  
指定されたMp3の確定的なメタデータを生成します。
  

Requirements  
------------  
Windows 10/11  
  

For users  
---------  
Download the latest MusicDiskBuilder.exe from Releases and run it.  
  

For development  
---------------  
Install dependencies:  
    `python -m pip install -r requirements.txt`

Run:  
    `python run_gui.py`

Build:  
    `build.bat`
